# Santosh Itkare Portfolio

A **React + Vite + Tailwind CSS** portfolio website showcasing Santosh Itkare’s professional profile, projects, skills, and contact form. Fully responsive, supports dark/light toggle, and optimized for static hosting.

---

## Features

- React functional components with clean structure
- Tailwind CSS for styling
- Dark/light mode toggle
- Portfolio sections: About, Skills, Experience, Projects, Testimonials, Contact
- Fully static-ready (can deploy on GitHub Pages, Netlify, Vercel)
- Minimal dependencies for fast loading (0.1 CPU + 512MB RAM compatible)

## Getting Started

1. **Clone the repo**
```bash
git clone https://github.com/yourusername/santosh-portfolio.git
cd santosh-portfolio

npm install

npm run dev

npm run build

npm run preview
```
## Notes
Make sure Node.js 18+ is installed.

Tailwind CSS classes are purged automatically in production.

To use the contact form, connect it to StaticForms
 or Formspree
.
